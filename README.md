# itinerary-react

瑞士行程（26EC805CX．經典瑞士三峰三火車12日團）React 版靜態網站。

原始資料來源：[switzerland-trip-itinerary](https://github.com/linjinhsien/switzerland-trip-itinerary)（純 HTML 版）。

## 開發

```bash
npm install
npm run dev
```

## 建置

```bash
npm run build
```

## 部署

Push 到 `main` 分支會自動觸發 GitHub Actions，建置後部署到 GitHub Pages。

線上網址：https://linjinhsien.github.io/itinerary-react/
